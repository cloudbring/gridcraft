# Legacy output fixtures

Captured on 2026-11-03 from the untouched ticket #70 GridCraft tree, before
deleting version.rs, stats.rs or ico.rs and before replacing the layer checker.
Only first-party code and synthetic inputs were used; no vendor artifacts.

- `layers.stdout`: old binary's complete `layers` output on the current workspace.
  Fixed-width rows with no dependencies intentionally retain trailing spaces.
- `metadata.json`: the corresponding `cargo metadata --no-deps` graph, reduced
  to package/dependency names, kinds and local-path presence for portable tests.
- `stats-repo.stdout`: old binary's full current-tree report. Only xtask/TOTAL
  rows are excluded from comparison because the task's own sources change.
- `version.*`: old version task on an isolated dependency-free workspace copy
  using GridCraft's current workspace version, then `set 1.2.3-rc.1`. Preserve
  stdout, the input/updated manifest and the Cargo-generated updated lockfile.
- `stats.stdout`: old task on that synthetic workspace, with a single test source
  plus excluded target/fuzz/dot directories. Shared tests add directory aliases
  and a cycle to verify bounded deduplication without compiling other packages.
- `ico.stdout`, `ico.hex`: old task packing synthetic 16/32/48/256-pixel IHDR
  inputs into `out.ico`, in that order. Hex encodes the complete file bytes.
- `parity-write.stdout`, `parity-check.stdout`, `parity.md`: old engine-backed
  task writes/checks relative `parity.md` in a temporary directory. Tests assert
  stdout, complete generated bytes, and non-writing stale-check failure.

Captures used `CARGO_TARGET_DIR` set to this worktree's `target-70`. Temporary
standalone drivers linked the already-built xtask dependencies and called the
original task modules with an isolated root; version never edited this checkout.
The reproduction driver is a subprocess of the integration-test executable;
only its explicit output framing and Rust test-harness text are removed before
byte comparison. No legacy implementations are vendored into production/tests.

Fixtures together are below 200 KB. They are captured evidence, not regenerated
from the shared implementation. Refresh only against an independently verified
legacy implementation or after an intentional behavior change.
